# きゆのひみつ金庫(ブログサイト)

知らないと損する税金・給付金・国の制度を、元税務職員の「きゆ」がやさしく解説するブログです。
HTML と CSS だけで作っているので、特別なソフトは不要です。

- 公開予定アドレス:https://kiyu-vault.github.io/
- GitHubユーザー名:kiyu-vault

## 見かた

`index.html` をダブルクリックすると、ブラウザで開けます。

## ファイル構成

| ファイル | 中身 |
|---|---|
| index.html | トップページ(記事一覧・プロフィール・カテゴリー) |
| article.html | 記事ページ(医療費控除の基本。ふきだし・表・チェックリスト・計算ツールの見本も兼ねています) |
| about.html | プロフィールページ |
| style.css | 見た目(色・文字・配置) |
| script.js | 動き(スマホメニュー・計算ツール・上に戻るボタン) |

## よくある変更

- **色を変える** → `style.css` の一番上 `:root` の色コードを変更
- **新しい記事を追加** → `article.html` をコピーして名前を変え、本文を書き換える。`index.html` にカードを1つ追加
- **アイコン画像を使う** → 絵文字(🔐)の部分を `<img src="画像ファイル名">` に置き換え

## 書きかけの箇所

公開前に、次の「(記事タイトルが入ります)」「(例)」の部分を書き換えてください。

- index.html:2本目以降の記事カード(仮のタイトル)
- about.html:自己紹介文、経歴、SNSリンク
- 各ページ:お問い合わせ、プライバシーポリシーのリンク先
